# Лабораторная работа №6. Продвинутый HTML. Введение в CSS стили. 

## О проекте
Данный проект представляет собой простую веб-страницу-визитку, созданную в рамках самостоятельного задания к лабораторной работе №6 "Продвинутый HTML. Введение в CSS стили. Создание простого сайта про историю ЭВМ".

## Что было в лабораторной работе №6
В ходе выполнения лабораторной работы были изучены следующие темы:
1. **Блочные и строчные теги** - div, span, p, h1 и их отличия
2. **Теги форматирования текста** - b, strong, i, em
3. **Ссылки** - абсолютные, относительные, якорные, mailto, tel, download
4. **Изображения** - тег img, атрибуты alt, width, height, loading="lazy"
5. **Цитаты** - blockquote, cite
6. **Медиаконтент** - video, audio, iframe
7. **Формы и input** - различные типы полей ввода
8. **Семантическая верстка** - header, nav, main, section, aside, footer
9. **Основы CSS** - селекторы (по тегу, классу, id), каскадность, box-sizing
10. **CSS Grid и Flexbox** - создание сеток и гибких макетов
